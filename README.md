# Location-Based Restaurant Analysis

A geographical analysis project examining restaurant data to uncover location-based trends across cities and regions.
## Tools Used
Python, Pandas, Matplotlib/Seaborn

## What it does
- Explores restaurant distribution across different locations
- Analyzes patterns like cuisine popularity, ratings, and pricing by region
- Visualizes geographical trends to surface actionable insights

## Key Learnings
Applied data analysis and visualization techniques to understand how location impacts restaurant performance and customer preferences.
